# المحاسب الشامل | Al-Muhasib Pro

تطبيق محاسبي عربي موجّه للهاتف، يركّز على سهولة الاستخدام، سلامة القيود، والعمل المحلي دون اتصال.

## الحالة الحالية

هذا المستودع يبدأ بنسخة تأسيسية قابلة للتطوير. النسخة الأولى تركّز على واجهة عربية RTL، لوحة متابعة، تسجيل الحركات، طبقة تخزين محلية، واختبارات آلية. لا تُستخدم هذه النسخة بعدُ لإدارة حسابات حقيقية قبل اجتياز الاختبارات والتحقق المحاسبي.

## مبادئ التصميم

- العربية واتجاه RTL من البداية، مع بنية تسمح بإضافة الإنجليزية.
- دفتر حركات محلي؛ لا تُرسل البيانات المالية إلى خادم دون اختيار صريح من المستخدم.
- فصل الواجهة عن منطق الحسابات والتخزين.
- عدم اعتماد أي قيد مزدوج غير متوازن.
- النسخ الاحتياطي لا يُعتبر ناجحًا إلا بعد التحقق من الملف الناتج.
- اختبارات آلية وبناء Android عبر GitHub Actions.

## تشغيل التطبيق

يتطلب Flutter stable وDart المتوافقين مع إصدار Flutter المثبت:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## خارطة الطريق

1. دفتر الحركات المحلي ولوحة المؤشرات.
2. دليل الحسابات والقيود المزدوجة والأستاذ العام.
3. العملاء والموردون والفواتير وسندات القبض والصرف.
4. المخزون والمشتريات والمبيعات.
5. ميزان المراجعة وقائمة الدخل والميزانية والتدفقات النقدية.
6. PDF/CSV، النسخ الاحتياطي والاستعادة، ثم اختبارات الجهاز الفعلي.

## تنبيه

هذه برمجية قيد التطوير وليست بديلًا عن مراجعة محاسب مختص أو التحقق من المتطلبات الضريبية المحلية.
